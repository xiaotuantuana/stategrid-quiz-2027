# 国网题库2027 · Windows桌面版

依据2027其他工学类考纲整理的个人离线备考工具，与国家电网及考试组织方没有隶属或背书关系。

## 下载

**[下载最新版 v2027.1.2 Windows 64位免安装版](https://github.com/xiaotuantuana/stategrid-quiz-2027/releases/download/v2027.1.2-desktop.20261022/stategrid-quiz-2027-windows-x64-v2027.1.2.zip)**

完整解压ZIP，进入“国网题库2027”文件夹，双击“国网题库2027.exe”。保留同目录 `_internal`，无需安装Python，刷题无需联网。
适用Windows 10/11 64位；不要在压缩包预览中运行，不要只复制exe。

## 学习记录

每位使用者的记录保存在本机 `%LOCALAPPDATA%\StateGridQuiz2027`，发布包不含制作人的学习记录。
Ctrl+S导出、Ctrl+O导入；每分钟及退出自动备份。现有保留题目的记录兼容旧版。
已移除题目不再展示；包含已移除题目的旧试卷归档，建议重新组卷。
Ctrl+加号/减号缩放字号，F11全屏。
