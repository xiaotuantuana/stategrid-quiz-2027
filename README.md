# 国网题库 2027 · Windows桌面版

依据2027其他工学类考试大纲整理的离线备考工具，支持考纲练习、练习卷、错题本、收藏、搜索、进度备份。
这是个人备考项目，与国家电网及考试组织方没有隶属或背书关系。

## 下载与使用

**[下载 Windows 64位免安装版](https://github.com/xiaotuantuana/stategrid-quiz-2027/releases/download/v2027.1.1-desktop.20261022/stategrid-quiz-2027-windows-x64-20261022.zip)**（约229 MB）

1. 下载完整ZIP文件并解压。
2. 打开解压后的“国网题库2027”文件夹。
3. 双击“国网题库2027.exe”，无需安装Python，可离线练习。

适用 Windows 10 / 11 64位。必须保留同目录的 `_internal` 文件夹；不要只复制exe，也不要直接在压缩包预览中运行。

## 题目与选项

- 共5280条可练题目：官方参考题832、旧库筛选保留655、公开课程中文改编100、原创概念126、原创计算参数变式3567。
- 参数变式来自150个计算题型，不代表3567个独立题型；上述题目也不等于正式考试真题。
- 四选一正确答案位置按当前练习组均衡分配，A/B/C/D数量最多相差1，再随机打乱；多选题选项也随机排列。
- 每题可查考点与来源；课程改编题标明原作者、原题页码及许可。部分旧库答案未逐题复核。

## 学习记录

本发布包不包含制作人的学习记录、收藏或账号。记录保存在各自电脑的 `%LOCALAPPDATA%\StateGridQuiz2027`。
软件每分钟及退出时自动备份。`Ctrl+S` 导出、`Ctrl+O` 导入；换电脑前请导出JSON备份。
`Ctrl+加号/减号` 调整字号，`F11` 全屏。来源网页链接需要网络，刷题本身无需联网。
